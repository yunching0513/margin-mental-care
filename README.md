# 留白 · Margin

一個以神經科學為地基、以文學感為外衣的心理照顧 App。

> 定位:**不是心理疾病治療器材,而是「日常神經調節與自我關係的練習場」。**

## 設計上的三個立場

| 立場 | 說明 |
|---|---|
| **可驗證的溫柔** | 每個功能都能指出它在改變哪一條神經迴路、根據哪一種治療法。使用者可以「點進去看為什麼」。 |
| **不製造情緒債** | 不用連續天數、不用綠格子、不用「你已經三天沒有照顧自己了」。錯過就是錯過。 |
| **留白即功能** | App 的成功指標之一是**使用者停留時間下降**。 |

## 目前的決策

- **iOS 先行** — SwiftUI + SwiftData,同步走 CloudKit 私有資料庫(伺服器不存書寫內容)
- **AI 進 v1** — 危機偵測完全在裝置端;生成類功能逐次授權上雲,不保留、不訓練
- **社群延到 v1.0** — 只做匿名漂流瓶與同在感兩項
- **目標族群由前期調查決定** — 不預設
- **情緒急救永遠免費、不需登入、離線可用**
